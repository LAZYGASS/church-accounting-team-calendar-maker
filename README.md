# 재정회계팀 일정 캘린더

`web/index.html`을 브라우저에서 열어 연도를 선택하고 월별 이미지를 저장합니다.
Python PPT 생성기는 `ppt_template_generator.py`입니다.

## 현재 일정 기준

- 집행일: 매월 두 번째·네 번째 화요일. 달력의 행 번호가 아니라 해당 요일의 등장 순서입니다.
- 결재일: 각 집행일 4일 전 금요일과 3일 전 토요일. 마감은 토요일 24:00(일요일 00:00)입니다.
- 운영위원회: 해당 월의 마지막 일요일에서 7일 전.
- 2026년 1월: 집행 13·27일, 결재 9·10·23·24일, 운영위원회 18일.

이 기준이 과거 기획 문서·예시보다 우선합니다. 기존 PPT 파일은 재생성하지 않았습니다.

## 검증

```sh
node --test tests/calendar.test.cjs
python -B tests/test_python_schedule.py
```

두 테스트는 추가 패키지 없이 2000~2100년 날짜 규칙을 검증합니다.
PPT 파일 생성에는 기존 의존성인 `python-pptx`가 필요합니다.
